# 중앙부처동향 — 별도 AI API 없는 기사 발췌 도구

## 중요한 사항
- 이 압축파일에는 **Windows EXE 자체가 아니라 소스와 EXE 빌드 설정**이 들어 있습니다. 현재 제공 환경에서는 Windows EXE를 직접 제작하거나 실행 테스트할 수 없습니다.
- Windows에서 빌드한 EXE는 사용자 PC에 Python 설치 없이 실행할 수 있습니다. **기사 페이지를 읽을 때 인터넷은 필요**합니다.
- 이것은 AI 요약이 아닙니다. 본문에서 문장을 선택하는 **발췌형 요약**입니다. 본문이 충분하지 않으면 사이트가 공개한 설명문을 표시하며, 둘 다 없으면 실패 사유를 표시합니다. 구글 검색결과를 기사 원문처럼 취급하지 않습니다.

## Python을 설치하지 않고 EXE 얻기 (GitHub Actions)
1. GitHub 계정에서 새 개인 저장소를 만들고 **압축을 푼 폴더 안의 파일들**(`app.py`, `requirements.txt`, `.github/workflows/build-windows.yml` 등)을 저장소 루트에 올립니다. `.github` 폴더가 숨겨져 있을 수 있으므로 누락되지 않게 확인하세요.
2. 저장소의 **Actions → Windows EXE build → Run workflow**를 누릅니다. GitHub Actions 사용이 비활성화된 저장소라면 활성화해야 하며, 저장소 설정·계정에 따른 사용량 제한/요금이 적용될 수 있습니다.
3. 완료된 실행의 **Artifacts → article-report-windows**에서 ZIP을 다운로드하고 압축을 풀어 EXE를 실행합니다. 출처를 알 수 없는 EXE 실행 시 Windows 보안 경고가 뜰 수 있으므로 본인이 빌드한 파일인지 확인하세요.

Python이 이미 설치된 Windows PC라면 `build_windows.bat`로 빌드할 수 있습니다.

## 사용법
1. EXE 실행 → **기사 엑셀 열기**에서 `.xlsx` 선택.
2. 정치·경제·사회일반·해외동향·오피니언은 기사 행이 아니라 구분 행입니다. 그 뒤의 기사들을 해당 탭에 넣습니다.
3. 각 기사 묶음의 첫 행이 제목 옆 매체를 가진 대표 기사이고, 나머지는 `보도매체`에 정해진 매체 우선순위로 표시됩니다.
4. **이 기사 발췌** 또는 **모든 대표 기사 발췌**를 누릅니다. 원문/공개 설명문을 읽지 못하는 경우 `[요약 불가]`가 표시됩니다.
5. 발췌가 완료되면 **HTML로 내보내기**를 눌러 저장 위치를 선택하세요. 저장한 `.html`은 브라우저에서 오프라인으로 열 수 있는 정적 보고서입니다. 발췌 전 카드는 `[미발췌]`, 실패한 카드는 `[요약 불가]`로 기록됩니다. 새 기사 발췌는 EXE에서 다시 진행해야 합니다.
6. **원문 열기**로 발췌문을 원문과 대조하세요. 엑셀 `요약` 열이 있다면 열기 직후 그 값이 보이지만, 발췌 버튼을 누르면 화면의 내용이 바뀝니다. 발췌 결과는 엑셀에 저장되지 않습니다.

## 주의
- 유료·로그인·자동 접근 차단 페이지는 읽을 수 없습니다. 언론사 페이지 구조 변경 시 본문 추출도 실패하거나 불필요한 문장이 포함될 수 있습니다.
- 동일기사 묶음은 엑셀 예시의 DMZ·미중회담·북포로 등 제목 키워드와 제목 일치를 이용합니다. 오묶음 가능성이 있으므로 결과를 확인해야 합니다.
- 프로그램은 기사 사이트에 직접 요청합니다. 사이트의 이용 조건과 저작권을 준수해 사용하세요.
- 엑셀은 인터넷이나 AI 서비스로 전송하지 않습니다. 발췌할 대표 기사의 URL에만 요청합니다.

## 기존 GitHub 저장소 업데이트
GitHub Desktop의 **Show in Explorer**로 저장소 폴더를 연 다음, 이 ZIP 안의 `app.py`와 `README.md`를 그 폴더의 같은 이름 파일에 덮어씁니다. `Changes`에서 변경사항 확인 → Summary 입력 → **Commit to main** → **Push origin**. GitHub **Actions → Windows EXE build → Run workflow**를 다시 실행하고 **새 실행**의 Artifacts에서 EXE를 받으세요. 기존 EXE는 자동으로 바뀌지 않습니다.
